# Portfolio Dashboard

A personal portfolio built with **React 19**, **Vite 8**, and **Tailwind CSS v4**. Features a 3-theme system (modern/light/dark), 3D card hover effects, horizontal scrollable project cards, and a scroll-aware sticky navbar.

## Tech Stack

- **React 19** — UI library
- **Vite 8** — Build tool
- **Tailwind CSS v4** — Utility-first CSS
- **Framer Motion** — Animations
- **Lucide React** — Icons

## Features

- 3-theme toggle (modern / light / dark) persisted in localStorage
- 3D transform hover effects on all cards
- Horizontal scroll for project cards with gradient overlay arrows
- Responsive design with mobile hamburger menu
- All content driven from a single data file (`src/data/profile.js`)

## Sections

Hero — About — Experience — Honors — Skills — Projects — Publications — Certifications — Education — Profiles — Contact — Footer

## Quick Start

```bash
npm install
npm run dev      # → localhost:5173
npm run build    # → dist/
npm run lint     # ESLint
```
